# 管理学综述写作

将分散研究转化为可追溯、可比较且有增量解释的知识结构。以范文学习论证动作，依据当前研究问题选择方法与结构；不把范文的历史结论、检索窗口或具体模型当成通用模板。

## 使用方式

- **定位或提纲**：读取 [规划与综合](references/planning-and-synthesis.md)，确定问题、贡献目标、证据方法和主分类轴，再给有论证职责的提纲。
- **写作或修改**：读取 [写作与审读](references/writing-and-review.md)，依据已经核验的证据写作；优先改善概念、比较和推理，再润色语言。
- **评估综述**：用同一参考文件中的类型适配检查与评分表；用户只要求评价时，给出问题位置、影响和修订方案，不擅改原稿。
- **找范文或学习某种写法**：先读 [范文索引](references/exemplar-index.md)，只打开当前任务所需的逐篇笔记。无需默认加载全部范例。

默认采用用户使用的语言。中文以自然的学术简体中文表达；英文保持目标期刊的论证习惯，避免将中文段落逐句翻译。

## 开始前确定六件事

1. **对象与问题**：具体要解释或澄清什么，属于哪个分析层次？
2. **现有基线**：相邻综述已经解决了什么，为什么还需要本篇？
3. **贡献目标**：概念澄清、理论比较、机制整合、证据裁决、方法诊断，或其他明确产出。
4. **证据方法**：有边界说明的整合评述、系统检索与编码、计量辅助内容分析、元分析等。
5. **读者与出口**：学习材料、学位论文综述章节、独立综述投稿、修稿或审稿；目标期刊若未确定，不捏造期刊要求。
6. **可用材料与真实读取状态**：已有文献清单、全文、编码、稿件、检索日志分别有哪些？

用户只提供宽泛主题时，先给2–3个可回答的知识问题和各自适用路线，并只询问影响下一步的关键缺口。可以同步核对已有综述和材料；不要在没有证据集合时直接写出带确定事实结论的完整综述。

## 核心操作

### 由问题选择路线

分别选择“贡献目标、证据处理方法、叙事组织主轴”，允许组合。系统检索不自动产生理论贡献；整合综述也应交代选材边界。元分析需要效应量等实际数据，不能用叙述性结论伪造统计结果。

### 建立可比较的证据

先比较既有综述，确定本篇的增量；再把问题转成纳排和编码字段。依据任务保存文献清单、检索日期、来源、筛选理由与编码分歧。检索式、来源范围、实际纳入文献和正文展示的代表研究分别记录。

阅读状态区分：元数据、摘要、部分正文、全文正文、图表/附录是否核对。不能由“下载成功”推定“全文已读”，也不能由“读了某综述”推定“读了其全部参考文献”。扫描或乱码材料先OCR/视觉补读，再作依赖细节的判断。

关键定义、假设、量表和机制优先回到原始出处核验。范文也可能出现引文编号错配；获奖或高引用不使其每项方法主张自动成立，方法能否处理内生性等问题仍需独立论证。

### 从分类走向综合

主轴应有理论或问题依据，例如概念角色、机制、过程、层次、研究用途；解释它为何比作者顺序或关键词簇更能回答问题。用统一字段比较研究，保留相反结果、测量差异、层级差异及空格。不要为填满表格或四象限编造证据。

每个主题段落完成：`该主题的判断 → 多项证据的共同点/分歧 → 分歧来自哪里 → 本文形成的新认识或边界`。必要时逐篇讨论关键研究，随后回到综合判断。

先判定是否真的存在矛盾：检查构念、单位、因变量、时间、样本、研究设计。可以调和的差异给出桥接逻辑；无法调和的理论前提和证据冲突明确保留。

### 让图表承担论证

定义表说明概念选择的解释或测量后果；比较表使用共同维度；样本图描述文献分布；理论图表达关系与边界；议程表连接缺口和研究设计。发文增长、共现聚类、图表数量本身不构成理论贡献。

每个节点、象限和箭头均能回到证据或明确标记的推论。标明箭头表示引用、组成、时间、关联、机制假设还是因果证据；不要将谱系箭头或框架中的关系自动读成因果。

### 将综合转成研究议程

每项议程至少说明：`已有发现/矛盾 → 仍不能回答的问题 → 可能机制或竞争解释 → 可行对象、数据与设计 → 回答后改变什么理论认识`。

议程沿正文主轴展开。中国情境应进入机制、假设或边界；不能只增加地名或传统文化词语。算法、变量、地区或样本的增加，只有改变解释或证据能力时才有贡献。

### 完成写作并校验贡献

引言建立必要性、相邻综述基线、明确问题和具体产物；主体的分类、图表和议程共同回答这些问题；结尾逐项兑现贡献并界定限制。视任务交付提纲、证据矩阵、框架说明、议程矩阵、正文或修订意见，避免用户只要一个阶段却生成整套材料。

## 范文库与质量信号

本库英文主题范文按UTD24期刊筛选；中文来自《管理世界》《外国经济与管理》《南开管理评论》。这限制的是**范文选择**，未来具体主题的证据纳入由问题与方法决定，不自动排除其他期刊和异议文献。UTD、基金委重要期刊、FMS是不同口径，核实版本与来源后再表述。

评价时优先判断理论贡献、综合能力、证据处理与表达。引用、下载、同行奖项和转载提供辅助信号；计量值附数据库及日期，在相近年份、领域和文类内比较。人大全文、文摘、索引分开记录；访问量不写成下载量；作者奖项不写成论文奖项；作者名气不代替内容判断。

## 输出前的关键检查

- 是否实际回答了引言提出的问题，并说明相对哪些既有综述有何新增？
- 定义、分析层次、分类和因果措辞是否前后一致？
- 新框架的每个部分能否回到已读证据，哪些仍是待检验推论？
- 对反例、失败、未找到证据和检索/读取限制是否如实呈现？
- 主题综述、写作指南、经验事实与本次写作判断是否分清？
- 参考文献元数据和关键定位是否已核实？旧范文中的技术判断及期刊政策是否需要重新查证？

使用机构资源时沿正常授权入口操作，优先复用已授权会话；需要用户本人交互的验证码或身份核验再交回用户。不将账号、密码、验证码、会话或带签名的代理链接写入文档或skill。只把公开书目、稳定链接、原创分析与实际读取状态加入可复用库。
